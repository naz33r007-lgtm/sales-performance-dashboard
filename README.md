# Sales Performance Dashboard

### 📊 Overview
This project analyzes sales data to identify revenue trends, top-performing products, and regional performance. The goal is to create a Power BI dashboard that helps businesses make data-driven decisions.

### 🧩 Objectives
- Analyze sales and profit across regions, time, and product categories.  
- Create interactive visualizations using Power BI.  
- Identify top-performing and underperforming segments.  

### 🧠 Skills Used
Power BI, Excel, Data Cleaning, DAX, Data Visualization, Storytelling  

### 📁 Dataset
Sample dataset from [Kaggle - Sample Superstore Sales Data](https://www.kaggle.com/datasets/kyanyoga/sample-sales-data)

### 📈 Key Insights
- Top 10 products contribute 60% of total revenue.  
- West region shows the highest profit margin.  
- Seasonal sales peaks observed during Q4.
